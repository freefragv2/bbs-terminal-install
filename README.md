# Установка BBS Terminal

BBS Terminal поставляется двумя пакетами. Первый содержит торговое ядро и веб-интерфейс. Второй содержит суперклиент со Стражем.

1. Получите персональную ссылку на нужный пакет у владельца BBS Terminal.
2. Откройте ссылку и нажмите **Скопировать команду установки**.
3. Войдите по SSH на сервер Ubuntu 26.04 amd64 под root. Выполните скопированную команду и следуйте подсказкам установщика.

Одно приглашение даёт одну установку одного пакета. Первый запуск команды нужно выполнить в течение 24 часов после выдачи ссылки. Если установка прервётся, повторите ту же команду на том же сервере. Для каждой новой установки получите отдельную ссылку.

Пакеты раздаёт ББШ по приглашению. Аккаунт и токен GitHub для установки не нужны. Загрузчик проверяет подпись установщика, а тот проверяет подпись и контрольную сумму пакета. Автообновления используют ключ установки, который создаётся на сервере.

Файл [install.sh](install.sh) — открытая копия загрузчика. Готовая команда для вашей установки находится на странице приглашения. Храните ссылку в личной переписке.
